1. 기본 개념 정리
Git: 코드 바뀔 때마다 스냅샷 찍어서 저장해두는 버전 관리 도구

GitHub: Git으로 기록한 데이터들을 올려두는 온라인 저장소


git add . : 변경된 파일들 일단 담는 것.

git commit -m "내용" : 바구니에 담은 것들에 이름표 붙여서 저장

git push origin main : 저장된 기록들을 깃허브로 쏜다.

3. 상황별 명령어 모음
세팅: git init (여기서부터 관리 시작)

연결: git remote add origin [주소] (내 컴퓨터랑 깃허브 저장소랑 연결)

확인: git status (뭐가 수정됐는지 어떤걸 수정해야되는지 확인)

복제: git clone [주소] (남이 만든 거나 내 원격 저장소 그대로 내 컴퓨터로 땡겨온다)

동기화: git pull origin main (깃허브에 새로 올라온 거 있으면 내 컴퓨터로 가져온다)

4. 협업할 때 필요한 거
Branch: 원본 건드리면 위험하니까 옆으로 길 하나 더 내서 작업

Merge: 옆길에서 작업 끝난 거 다시 원본에다가 합친다

PR (Pull Request): "나 이거 다 고쳤는데 확인하고 합쳐줘"라고 요청 보낸다

cd :  경로 설정
